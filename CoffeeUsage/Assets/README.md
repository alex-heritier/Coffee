# Provider brand icons

Real provider marks used for the provider tabs and overview rows (replacing
generic SF Symbols). All are used nominatively to identify the services, the
same way CodexBar uses them. Loaded at runtime from the app bundle's
`Resources` directory as template images (tinted) or brand colors.
